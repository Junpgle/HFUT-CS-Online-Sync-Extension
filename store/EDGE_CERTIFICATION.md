# Microsoft Edge Partner Center · 审核表单参考

> 项目「HFUT-CS-Online 全站学习同步」的审核辅助材料。下列描述依据仓库当前 JavaScript 和商店专用 ZIP 内容编写；正式提交前以你实际上传的包为准。

## 1. Single Purpose（扩展的唯一用途）

在 HFUT-CS-Online 指定学习网站中保存并跨设备同步课程答题结果和阅读位置，并允许用户查看、导出、恢复和按课程清理这些学习进度。扩展不会修改网站源码，也不对其他网站执行内容脚本。

## 2. Permission justification（权限使用理由）

### `storage`

必须使用浏览器的 `chrome.storage.local` 缓存本机同步状态，并使用 `chrome.storage.sync` 同步题目状态与课程阅读记录；用户还需要读取云端占用量并按课程清理记录。

### `activeTab`

用户打开扩展弹窗或点击「立即同步」「刷新网页」时，需要识别当前正在浏览的学习网站标签页、向该页面的已安装内容脚本发送同步指令或刷新网页。只在用户主动操作扩展界面时执行。

### 网站访问权限：`https://saltgardenia.github.io/HFUT-CS-Online/*`

内容脚本只在该站点运行，以读取对应的 `localStorage` 做题进度、读取滚动位置并恢复学习记录。**正式发布包不包含本地开发网址**，也不使用全网站通配符权限。

## 3. Remote Code

选择 **No, I am not using remote code**。

扩展使用 Manifest V3。运行代码均由扩展包中的 `shared.js`、`content.js`、`popup.js` 提供；`popup.html` 只加载扩展包内的静态资源。没有远程脚本、`eval` 或自定义脚本加载器。用户点击外部链接打开学习网站或仓库，并非下载执行远程代码。

## 4. Data usage / 隐私披露

应如实披露**与网站学习活动相关的数据**：课程代号、题目 ID、答题状态、页面路径/标题、阅读进度与滚动位置、记录时间及随机设备标识。

这些数据用于显示学习进度、跨设备同步与冲突处理。扩展会将其存入浏览器的 `storage.local` 和 `storage.sync`；同步数据可能通过 Microsoft Edge 的浏览器账号同步服务传输和保存。扩展没有自主运营的远端数据库，也不会向开发者发送这些数据。

当 Partner Center 的隐私类别中存在「网站内容 / Website content」或与学习活动相关的字段时，应按当前表单定义审慎选择；**不要直接勾选“完全不处理用户数据”**。扩展不获取 Cookie、凭据、金融或健康数据，不提供广告、追踪、营销或第三方分析功能。

## 6. Notes for certification（可以复制到审核备注）

这是用于独立公开课程学习网站 HFUT-CS-Online 的伴随扩展，目标网站是 https://saltgardenia.github.io/HFUT-CS-Online/ 。

**最短验证路径：**

1. 在 Edge 安装扩展，访问上面的公开网站（无需登录）。
2. 打开该站点的任意课程，例如「计算机网络」，进入「在线练习」并完成若干题。
3. 点击浏览器工具栏中的扩展图标，可查看已记录题数、答对题数和课程管理项目。
4. 在课程正文页面向下滚动，稍后再次打开扩展弹窗，查看阅读记录与「继续阅读」入口。
5. 在弹窗的「云端同步空间」区域查看已用、剩余容量。在「课程同步管理」对测试课程选择「清除并停用」，确认后该课程的同步存储记录被清除，网站自身的本地答题进度仍会保留；随后可「恢复同步」。
6. 「导出备份」生成本地 JSON；「导入备份」可以恢复兼容格式的扩展备份。
7. 如需验证**跨设备**，需在两个 Edge 桌面环境中登录同一 Microsoft 同步账号并启用扩展同步，实际传播速度受浏览器同步状态影响；单设备不一定能直接观察到跨设备变化。

**审核说明：** 本扩展不是 HFUT-CS-Online、合肥工业大学或 Microsoft 的官方产品。只访问上面这一学习网站，不调用开发者运营的 API。浏览器扩展同步数据有约 100 KiB 的容量限制；弹窗内能显示真实用量。扩展 UI 主要使用简体中文。
