# Microsoft Edge 加载项商店 · 简体中文上架文案

> 对应扩展 **HFUT-CS-Online 全站学习同步**。此文件用于复制到 Microsoft Partner Center，**不需要打包进扩展 ZIP**。

## 商店名称（由 manifest.json 决定）

HFUT-CS-Online 全站学习同步

## 商店简短介绍（由 manifest.json 决定）

为 HFUT-CS-Online 同步做题进度和阅读位置，支持学习统计、课程清理与 JSON 备份。

## 商店详细介绍（粘贴到「Description」）

HFUT-CS-Online 全站学习同步是一款面向 HFUT-CS-Online 学习网站的独立浏览器扩展。它可以在不改动原网站的情况下，为课程复习增加阅读记录与做题进度的跨设备同步，适合在 Microsoft Edge 的不同电脑和 Android 设备之间切换学习的用户。

**核心功能**

1. **跨设备做题进度**：自动识别网站已支持的课程答题记录，按照课程和题目分别保存「答对」「答错」「查看答案」状态。不同课程拥有相同题号时也不会混淆。
2. **继续阅读**：记录课程页面的阅读位置、页面标题和进度百分比。打开扩展面板，即可查看最近阅读的页面并跳转返回。
3. **同步空间管理**：实时展示浏览器同步空间的已用容量、剩余容量和各课程占用情况。可以按课程清除不再需要的云端学习记录并停止继续同步，之后也可以重新启用。
4. **学习进度概览**：按课程查看已有作答记录的题数和答对题数，快速了解复习情况。
5. **可选 Question-Bank 账号云同步**：用户可使用已有 Question-Bank 账号登录，通过 Cloudflare Worker + D1 的独立 HTTPS API 在电脑、Android 手机和平板之间同步课程答题状态和阅读记录。功能默认关闭，需用户主动登录。
6. **手动备份与恢复**：支持导出和导入 JSON 备份，用于保存学习数据或在不同浏览器间手动迁移。

**如何使用**

安装扩展后打开 HFUT-CS-Online 网站进行学习。扩展会读取网站已保存的相关做题记录，并在浏览器账号允许同步时，通过 Edge 的扩展同步存储在已登录相同账号的桌面设备之间传递数据。跨设备同步可能有延迟；如果另一台电脑已经打开做题页面，刷新网页后即可让页面读取新的进度。

**隐私与适用范围**

本扩展仅从指定 HFUT-CS-Online 网站读取学习记录，不访问其他网站的 Cookie 或浏览记录。默认使用浏览器本地存储及浏览器提供的账号同步。用户还可以主动登录 Question-Bank 账号，启用开发者运营的 Cloudflare 独立云同步：用户名和密码经 HTTPS 提交到现有 Question-Bank 登录接口，扩展不保存明文密码；云端会按账号保存学习进度，支持退出和删除。数据不用于广告或第三方分析，详细说明见隐私政策。

注意：浏览器账号同步仅适用于相应浏览器支持同步的环境；不同浏览器的同步空间不自动互通，已实测 Edge Android 可安装 v2.1.4，但 Edge 自带的扩展设置同步可能不运行；v2.2.0 新增独立云同步以绕开这一限制，手机与平板的新版互通效果仍需实机验证。浏览器同步存储存在容量限制。清除云端记录不会自动删除原网站保存在本机的做题记录。

本扩展是第三方独立项目，**并非合肥工业大学、HFUT-CS-Online 网站维护者或 Microsoft 的官方扩展**。
